# Lesson 6 — Тестування GrandmaGifts

## Завдання

Покрити тестами контракт GrandmaGifts (з Lesson 4) за допомогою Hardhat.

## Виконані тести

| № | Вимога | Статус |
|---|--------|--------|
| 1 | Бабуся може задеплоїти, внести кошти, задати онуків | ✓ |
| 2 | Сума правильно ділиться між онуками | ✓ |
| 3 | Успішне зняття у день народження | ✓ |
| 4 | Успішне зняття після дня народження | ✓ |
| 5 | Revert при знятті до дня народження | ✓ |
| 6 | Revert при повторному знятті | ✓ |
| 7 | Revert при виклику стороннього | ✓ |
| 8 | Подія Withdrawn з правильною адресою та сумою | ✓ |

## Запуск

```bash
cd "HomeWorkCrypta/Lesson 6"
npx hardhat test --config ./hardhat.config.js
```

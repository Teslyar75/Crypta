# WEB 1.0, 2.0, 3.0 — розгорнута довідка

## Web 1.0 (приблизно 1991–2004)

### Характеристики
- **«Read-only»** — інтернет лише для читання
- Статичні HTML-сторінки, мінімальна інтерактивність
- Контент створюють вебмайстри та компанії
- Одностороння комунікація: сайт → користувач
- Централізована архітектура: кожен сайт на власному сервері

### Типові приклади
- Інформаційні сайти-брошури
- Каталоги посилань (Yahoo Directory)
- Перші пошукові системи (AltaVista)
- Електронна пошта

### Обмеження
- Немає можливості легко додавати контент
- Відсутність соціальної взаємодії
- Повільне оновлення інформації

---

## Web 2.0 (приблизно з 2004 року)

### Характеристики
- **«Read-Write»** — читання та створення контенту
- Користувацький контент (UGC — User Generated Content)
- Соціальні мережі, блоги, вікі
- API для інтеграції сервісів
- AJAX, JavaScript — динамічні інтерфейси без перезавантаження сторінки

### Типові приклади
- **Соцмережі**: Facebook, Twitter, Instagram
- **Відео**: YouTube, TikTok
- **Спільне редагування**: Wikipedia, Google Docs
- **Хмарні сервіси**: Dropbox, Spotify

### Проблеми Web 2.0
- **Централізація**: великі компанії контролюють дані та платформи
- **Монетизація даних**: користувачі «продукт», реклама як основний дохід
- **Цензура та залежність**: платформа може заблокувати або змінити умови

---

## Web 3.0 (концепція з ~2014, активний розвиток)

### Характеристики
- **Децентралізація**: немає єдиного контролюючого центру
- **Власність даних**: користувач володіє своїми даними та цифровими активами
- **Блокчейн**: прозорість, незмінність, смарт-контракти
- **Семантична павутина**: машини краще розуміють зміст контенту
- **Токенізація**: криптовалюти, NFT, механізми мотивації

### Типові приклади
- **DeFi** (децентралізовані фінанси): Uniswap, Aave
- **NFT**: OpenSea, цифрове мистецтво
- **dApps**: застосунки на блокчейні (Ethereum, Solana)
- **IPFS, Arweave**: децентралізоване зберігання даних
- **DAO**: децентралізовані автономні організації

### Технології Web 3.0
- Блокчейн (Ethereum, Polygon, Solana)
- Смарт-контракти
- Криптографічні гаманці
- P2P-мережі
- Семантичні стандарти (RDF, OWL)

## Порівняльна таблиця

| Аспект | Web 1.0 | Web 2.0 | Web 3.0 |
|--------|---------|---------|---------|
| **Епоха** | 1991–2004 | 2004–дотепер | 2014–дотепер (в розвитку) |
| **Роль користувача** | Споживач | Учасник, автор | Власник, учасник економіки |
| **Дані** | На серверах сайтів | На серверах платформ | У користувача (гаманці, блокчейн) |
| **Монетизація** | Реклама, підписки | Реклама, дані користувачів | Токени, комісії в мережі |
| **Довіра** | Довіра до сайту | Довіра до платформи | Криптографія, код (trustless) |
| **Інтероперабельність** | Низька | API, інтеграції | Відкриті протоколи, кросплатформність |

---

## Висновок

Еволюція вебу йде від **пасивного споживання** (1.0) через **активну участь** (2.0) до **децентралізованої власності та економіки** (3.0). Web 3.0 не замінює повністю попередні версії — вони існують паралельно, але змінюють підхід до контролю даних, монетизації та довіри в інтернеті.

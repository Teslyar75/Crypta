# Порівняння версій WEB (1.0, 2.0, 3.0) — коротка відповідь

## Основні відмінності

| Критерій | Web 1.0 | Web 2.0 | Web 3.0 |
|----------|---------|---------|---------|
| **Суть** | Тільки читання | Читання + запис | Децентралізація, власність даних |
| **Контент** | Створюють сайти | Створюють користувачі (UGC) | Створюють користувачі, дані належать їм |
| **Технології** | HTML, статичні сторінки | AJAX, API, соцмережі | Блокчейн, смарт-контракти, семантична павутина |
| **Приклади** | Брошурні сайти, каталоги | Facebook, YouTube, Wikipedia | DeFi, NFT, dApps, IPFS |
| **Модель** | Централізовані сервери | Централізовані платформи | Децентралізовані мережі |

**Web 1.0** — пасивний інтернет: користувач лише переглядає готовий контент.

**Web 2.0** — інтерактивний інтернет: користувачі створюють контент, але платформи володіють даними.

**Web 3.0** — децентралізований інтернет: користувачі володіють даними, немає єдиного контролюючого центру.

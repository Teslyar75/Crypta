# Майнинг и механизмы консенсуса

## ⛏️ Что такое майнинг?

**Определение**: Процесс создания новых блоков и подтверждения транзакций с помощью вычислительной мощности.

**Цели майнинга**:
1. Добавление новых блоков в блокчейн
2. Подтверждение транзакций
3. Защита сети от атак
4. Распределение новых монет

## 🔨 Proof of Work (PoW)

### Принцип работы

**Задача**: Найти число (nonce), чтобы хеш блока удовлетворял условию.

**Условие**: Хеш должен быть меньше целевого значения (начинаться с определенного количества нулей).

**Пример**:
```
Цель: Хеш должен начинаться с 4 нулей

Попытка 1: SHA-256(блок + 1) = 8a3f5b9c... ❌
Попытка 2: SHA-256(блок + 2) = 7e2d1a8b... ❌
Попытка 3: SHA-256(блок + 3) = 5c9b3f2a... ❌
...
Попытка 2847593: SHA-256(блок + 2847593) = 0000a1b2... ✅
```

### Сложность майнинга

**Регулировка**: Каждые 2016 блоков (~2 недели) в Bitcoin

**Цель**: Поддерживать время создания блока ~10 минут

**Формула**:
```
Новая сложность = Старая сложность × (2 недели / Фактическое время)
```

### Награда майнера

**Состоит из**:
1. **Block Reward** — новые монеты
2. **Transaction Fees** — комиссии пользователей

**Bitcoin халвинг**:
```
2009-2012: 50 BTC за блок
2012-2016: 25 BTC за блок
2016-2020: 12.5 BTC за блок
2020-2024: 6.25 BTC за блок
2024-2028: 3.125 BTC за блок
...
~2140: 0 BTC (всего 21 млн)
```

### Оборудование для майнинга

**Эволюция**:
```
CPU (2009-2010)
  ↓
GPU (2010-2013)
  ↓
FPGA (2011-2013)
  ↓
ASIC (2013-настоящее)
```

**ASIC** (Application-Specific Integrated Circuit):
- Специализированные чипы только для майнинга
- В тысячи раз эффективнее CPU
- Дорогие, но окупаются

### Майнинг пулы

**Проблема**: Соло-майнинг слишком случаен

**Решение**: Объединение майнеров в пулы

**Принцип**:
```
1. Майнеры работают вместе
2. Делят награду пропорционально вкладу
3. Стабильный доход
```

## 🎯 Proof of Stake (PoS)

### Основная идея

**Вместо вычислительной мощности** → используется доля (stake) в сети

**Принцип**: Чем больше монет, тем выше шанс создать блок

### Как работает

```
1. Валидаторы блокируют монеты (стейкинг)
2. Алгоритм случайно выбирает валидатора
3. Выбранный создает блок
4. Получает награду
5. Если обманывает → теряет stake (slashing)
```

### Преимущества PoS

✅ Энергоэффективность (не нужны вычисления)  
✅ Меньше централизации (не нужно дорогое оборудование)  
✅ Экологичность  
✅ Быстрее PoW  

### Недостатки PoS

❌ "Богатые становятся богаче"  
❌ Меньше проверен временем  
❌ Сложнее реализация  
❌ Проблема "ничего на кону" (Nothing at Stake)  

### Примеры

- **Ethereum 2.0** (с 2022)
- **Cardano**
- **Polkadot**
- **Solana**

## 🔄 Другие механизмы консенсуса

### Delegated Proof of Stake (DPoS)

**Идея**: Держатели монет голосуют за делегатов

**Процесс**:
```
1. Пользователи выбирают делегатов (свидетелей)
2. Делегаты создают блоки по очереди
3. Быстрее и эффективнее PoS
```

**Примеры**: EOS, TRON, Steem

### Proof of Authority (PoA)

**Идея**: Доверенные валидаторы

**Использование**: Приватные блокчейны, тестовые сети

**Преимущества**: Очень быстро, энергоэффективно

**Недостатки**: Централизация

### Proof of History (PoH)

**Идея**: Криптографическое доказательство времени

**Использование**: Solana

**Преимущество**: Очень высокая скорость (65,000 TPS)

### Proof of Burn (PoB)

**Идея**: "Сжигание" монет для получения права майнить

**Процесс**: Отправка монет на адрес, с которого нельзя потратить

## ⚔️ Атаки на консенсус

### 51% атака

**Суть**: Контроль более 50% вычислительной мощности (PoW) или stake (PoS)

**Возможности**:
- Двойная трата
- Блокировка транзакций
- Отмена собственных транзакций

**Защита**:
- Большая сеть → дорого атаковать
- Репутационный ущерб
- Экономически невыгодно

### Selfish Mining

**Суть**: Майнер скрывает найденные блоки

**Цель**: Получить больше наград

**Защита**: Протокольные улучшения

### Nothing at Stake (PoS)

**Проблема**: В PoS валидаторы могут поддерживать все форки без затрат

**Решение**: Slashing (штрафы за двойную подпись)

## 📊 Сравнение консенсусов

| Параметр | PoW | PoS | DPoS |
|----------|-----|-----|------|
| Энергопотребление | Высокое | Низкое | Низкое |
| Скорость | Медленная | Средняя | Высокая |
| Децентрализация | Высокая | Средняя | Низкая |
| Безопасность | Проверена | Новая | Средняя |
| Барьер входа | Высокий | Средний | Низкий |

## 💡 Экономика майнинга

### Рентабельность

**Факторы**:
- Цена криптовалюты
- Сложность сети
- Стоимость электричества
- Эффективность оборудования

**Формула прибыли**:
```
Прибыль = (Награда × Цена) - (Энергопотребление × Стоимость кВт/ч)
```

### Хешрейт

**Определение**: Вычислительная мощность сети

**Единицы**:
- H/s (хеш в секунду)
- KH/s (тысяча)
- MH/s (миллион)
- GH/s (миллиард)
- TH/s (триллион)
- PH/s (квадриллион)
- EH/s (квинтиллион)

**Bitcoin сеть**: ~400 EH/s (2024)

# Криптовалюты: Полное руководство

Добро пожаловать в образовательный проект по изучению технологии криптовалют!

## 📚 Структура проекта

Этот проект содержит подробные материалы для изучения криптовалют и блокчейн-технологий:

### 📂 Основные разделы

1. **[01-Основы](./01-Основы/)** - Фундаментальные концепции
   - Что такое криптовалюта
   - Основная идея и философия
   - Отличия от традиционных валют

2. **[02-История](./02-История/)** - Эволюция технологии
   - Предпосылки создания
   - Этапы развития
   - Ключевые события

3. **[03-Технические-основы](./03-Технические-основы/)** - Как это работает
   - Блокчейн технология
   - Криптография
   - Майнинг и консенсус

4. **[04-Практика](./04-Практика/)** - Практическое применение
   - Кошельки
   - Транзакции
   - Примеры кода

5. **[05-Экосистема](./05-Экосистема/)** - Современное состояние
   - Основные криптовалюты
   - DeFi и NFT
   - Будущее технологии

## 🎯 Как использовать этот материал

1. Начни с папки **01-Основы** для понимания базовых концепций
2. Изучи **02-История** для контекста развития технологии
3. Погрузись в **03-Технические-основы** для глубокого понимания
4. Практикуйся с материалами из **04-Практика**
5. Исследуй **05-Экосистема** для понимания современного состояния

## 📖 Рекомендации по изучению

- Читай материалы последовательно
- Экспериментируй с примерами кода
- Делай заметки и задавай вопросы
- Изучай дополнительные ресурсы из списков литературы

Удачи в изучении! 🚀

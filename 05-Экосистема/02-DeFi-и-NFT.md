# DeFi и NFT

## 💰 DeFi (Decentralized Finance)

**Определение**: Финансовые услуги без посредников на базе смарт-контрактов.

### Основные сервисы

**1. Децентрализованные биржи (DEX)**
- Uniswap, PancakeSwap, SushiSwap
- Обмен токенов без посредников
- Автоматические маркет-мейкеры (AMM)

**2. Кредитование**
- Aave, Compound
- Займы под залог криптовалюты
- Автоматические процентные ставки

**3. Стейкинг и Yield Farming**
- Блокировка токенов для получения дохода
- Предоставление ликвидности

**4. Стейблкоины**
- DAI, USDC
- Стабильная стоимость

### Преимущества DeFi

✅ Доступность 24/7  
✅ Нет посредников  
✅ Прозрачность  
✅ Программируемость  

### Риски DeFi

❌ Уязвимости смарт-контрактов  
❌ Высокая волатильность  
❌ Сложность для новичков  
❌ Риск ликвидации залога  

## 🎨 NFT (Non-Fungible Tokens)

**Определение**: Уникальные цифровые активы, которые нельзя обменять 1:1.

### Применение NFT

**1. Цифровое искусство**
- Картины, музыка, видео
- Доказательство владения
- Роялти для авторов

**2. Коллекционирование**
- CryptoPunks, Bored Ape Yacht Club
- Уникальные персонажи

**3. Игры**
- Игровые предметы
- Персонажи
- Виртуальная земля

**4. Метавселенные**
- Виртуальная недвижимость
- Аватары
- Виртуальные товары

### Стандарты NFT

**ERC-721**: Стандарт для уникальных токенов  
**ERC-1155**: Полу-взаимозаменяемые токены  

### Популярные платформы

- **OpenSea** - крупнейший маркетплейс
- **Rarible** - создание и продажа NFT
- **Foundation** - для художников

## 🌐 Web3

**Концепция**: Децентрализованный интернет на базе блокчейна.

**Ключевые идеи**:
- Владение данными
- Децентрализованная идентичность
- Токенизированная экономика

# Безопасность смарт-контрактов

## ⚠️ Распространенные уязвимости

### 1. Reentrancy (Повторный вход)

**Проблема**: Внешний контракт может вызвать функцию повторно до завершения первого вызова.

**Уязвимый код**:
```solidity
// ❌ УЯЗВИМО!
function withdraw(uint amount) public {
    require(balances[msg.sender] >= amount);
    
    (bool success, ) = msg.sender.call{value: amount}("");
    require(success);
    
    balances[msg.sender] -= amount;  // Обновление после отправки!
}
```

**Безопасный код**:
```solidity
// ✅ БЕЗОПАСНО
function withdraw(uint amount) public {
    require(balances[msg.sender] >= amount);
    
    balances[msg.sender] -= amount;  // Обновление ДО отправки
    
    (bool success, ) = msg.sender.call{value: amount}("");
    require(success);
}
```

**Паттерн Checks-Effects-Interactions**:
```solidity
function withdraw(uint amount) public {
    // 1. Checks (проверки)
    require(balances[msg.sender] >= amount);
    
    // 2. Effects (изменения состояния)
    balances[msg.sender] -= amount;
    
    // 3. Interactions (внешние вызовы)
    (bool success, ) = msg.sender.call{value: amount}("");
    require(success);
}
```

### 2. Integer Overflow/Underflow

**Solidity 0.8+**: Автоматическая защита!

```solidity
// В 0.8+ это вызовет ошибку
uint8 x = 255;
x = x + 1;  // Ошибка!

// Для отключения проверки (не рекомендуется):
unchecked {
    x = x + 1;  // Переполнение без ошибки
}
```

### 3. Access Control (Контроль доступа)

**Проблема**: Отсутствие проверки прав доступа.

```solidity
// ❌ УЯЗВИМО
function withdraw() public {
    // Любой может вызвать!
    payable(owner).transfer(address(this).balance);
}

// ✅ БЕЗОПАСНО
address public owner;

modifier onlyOwner() {
    require(msg.sender == owner, "Not owner");
    _;
}

function withdraw() public onlyOwner {
    payable(owner).transfer(address(this).balance);
}
```

### 4. Delegatecall

**Опасность**: Выполнение кода в контексте вызывающего контракта.

```solidity
// ❌ ОПАСНО
function execute(address target, bytes memory data) public {
    (bool success, ) = target.delegatecall(data);
    require(success);
}
```

### 5. tx.origin для авторизации

```solidity
// ❌ УЯЗВИМО
function transfer(address to, uint amount) public {
    require(tx.origin == owner);  // Можно обойти!
    // ...
}

// ✅ БЕЗОПАСНО
function transfer(address to, uint amount) public {
    require(msg.sender == owner);  // Правильно
    // ...
}
```

## 🛡️ Best Practices

### 1. Используй OpenZeppelin

```solidity
import "@openzeppelin/contracts/access/Ownable.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract MyContract is Ownable, ReentrancyGuard {
    function withdraw() public onlyOwner nonReentrant {
        // Защищено от reentrancy
    }
}
```

### 2. Проверяй возвращаемые значения

```solidity
// ❌ Плохо
token.transfer(recipient, amount);

// ✅ Хорошо
bool success = token.transfer(recipient, amount);
require(success, "Transfer failed");
```

### 3. Используй события для важных действий

```solidity
event Withdrawal(address indexed user, uint amount);

function withdraw(uint amount) public {
    // ...
    emit Withdrawal(msg.sender, amount);
}
```

### 4. Ограничивай газ для внешних вызовов

```solidity
// Ограничение газа
(bool success, ) = recipient.call{value: amount, gas: 2300}("");
```

### 5. Проверяй входные данные

```solidity
function setPrice(uint newPrice) public {
    require(newPrice > 0, "Price must be positive");
    require(newPrice < 1000000, "Price too high");
    price = newPrice;
}
```

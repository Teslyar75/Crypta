# События (Events) в Solidity

## 📢 Что такое события?

**События** - это способ логирования данных в блокчейне. Они дешевле, чем хранение в storage, и позволяют фронтенду отслеживать изменения.

## 📝 Объявление событий

```solidity
contract EventExample {
    // Объявление события
    event Transfer(address indexed from, address indexed to, uint256 amount);
    event Deposit(address indexed user, uint256 amount, uint256 timestamp);
    
    function transfer(address to, uint256 amount) public {
        // Генерация события
        emit Transfer(msg.sender, to, amount);
    }
    
    function deposit() public payable {
        emit Deposit(msg.sender, msg.value, block.timestamp);
    }
}
```

## 🔍 Индексированные параметры

**indexed** - позволяет фильтровать события по этому параметру.

```solidity
event Transfer(
    address indexed from,    // Можно фильтровать
    address indexed to,      // Можно фильтровать
    uint256 amount          // Нельзя фильтровать
);

// Максимум 3 indexed параметра!
```

## 💻 Прослушивание событий (JavaScript)

```javascript
// Подписка на события
contract.on("Transfer", (from, to, amount, event) => {
    console.log(`${from} sent ${amount} to ${to}`);
});

// Получение прошлых событий
const filter = contract.filters.Transfer(null, userAddress);
const events = await contract.queryFilter(filter);
```

# Создание и использование кошелька

## 👛 Что такое криптовалютный кошелек?

**Определение**: Программа или устройство для хранения приватных ключей и управления криптовалютой.

**Важно понимать**: Кошелек НЕ хранит монеты! Монеты существуют в блокчейне. Кошелек хранит ключи для доступа к ним.

## 🔑 Типы кошельков

### 1. Горячие кошельки (Hot Wallets)

**Определение**: Подключены к интернету

**Типы**:

#### Веб-кошельки
- **Примеры**: Blockchain.com, Coinbase
- **Плюсы**: Удобно, доступ везде
- **Минусы**: Ключи хранятся на сервере

#### Мобильные кошельки
- **Примеры**: Trust Wallet, Exodus
- **Плюсы**: Удобно для платежей
- **Минусы**: Риск взлома телефона

#### Десктопные кошельки
- **Примеры**: Electrum, Bitcoin Core
- **Плюсы**: Больше контроля
- **Минусы**: Нужно обновлять

### 2. Холодные кошельки (Cold Wallets)

**Определение**: Не подключены к интернету

**Типы**:

#### Аппаратные кошельки
- **Примеры**: Ledger, Trezor
- **Плюсы**: Максимальная безопасность
- **Минусы**: Стоят денег (~$50-200)

#### Бумажные кошельки
- **Суть**: Приватный ключ на бумаге
- **Плюсы**: Бесплатно, офлайн
- **Минусы**: Легко потерять/повредить

## 📝 Seed-фраза (Мнемоническая фраза)

### Что это?

**Определение**: 12-24 слова, из которых генерируются все ключи кошелька.

**Пример**:
```
witch collapse practice feed shame open despair 
creek road again ice least
```

### Стандарт BIP39

**BIP39** (Bitcoin Improvement Proposal 39) — стандарт генерации seed-фраз

**Процесс**:
```
1. Генерация случайного числа (128-256 бит)
2. Добавление контрольной суммы
3. Разделение на группы по 11 бит
4. Каждая группа → слово из словаря (2048 слов)
5. Результат: 12-24 слова
```

### Безопасность seed-фразы

**КРИТИЧЕСКИ ВАЖНО**:
- ✅ Записать на бумаге
- ✅ Хранить в безопасном месте
- ✅ Сделать несколько копий
- ❌ НЕ хранить в электронном виде
- ❌ НЕ фотографировать
- ❌ НЕ отправлять никому

**Правило**: Кто знает seed-фразу = владеет всеми средствами!

## 🛠️ Создание кошелька (пример с Python)

### Установка библиотек

```bash
pip install bitcoin mnemonic
```

### Генерация seed-фразы

```python
from mnemonic import Mnemonic

# Создание генератора
mnemo = Mnemonic("english")

# Генерация seed-фразы (12 слов)
seed_phrase = mnemo.generate(strength=128)
print("Seed-фраза:", seed_phrase)

# Генерация seed из фразы
seed = mnemo.to_seed(seed_phrase, passphrase="")
print("Seed (hex):", seed.hex())
```

### Создание приватного и публичного ключа

```python
import hashlib
import ecdsa

# Генерация приватного ключа из seed
private_key = hashlib.sha256(seed).digest()
print("Приватный ключ:", private_key.hex())

# Генерация публичного ключа
sk = ecdsa.SigningKey.from_string(private_key, curve=ecdsa.SECP256k1)
vk = sk.get_verifying_key()
public_key = b'\x04' + vk.to_string()
print("Публичный ключ:", public_key.hex())
```

### Создание Bitcoin адреса

```python
import hashlib

def hash160(data):
    """SHA-256 + RIPEMD-160"""
    sha = hashlib.sha256(data).digest()
    ripe = hashlib.new('ripemd160', sha).digest()
    return ripe

def base58_encode(data):
    """Base58 кодирование"""
    alphabet = '123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz'
    num = int.from_bytes(data, 'big')
    encoded = ''
    while num > 0:
        num, remainder = divmod(num, 58)
        encoded = alphabet[remainder] + encoded
    return encoded

# Хеширование публичного ключа
hash_pub = hash160(public_key)

# Добавление версии (0x00 для mainnet)
versioned = b'\x00' + hash_pub

# Контрольная сумма
checksum = hashlib.sha256(hashlib.sha256(versioned).digest()).digest()[:4]

# Финальный адрес
address_bytes = versioned + checksum
address = base58_encode(address_bytes)

print("Bitcoin адрес:", address)
```

## 🔐 Подписание транзакции

### Создание подписи

```python
import ecdsa

def sign_transaction(private_key, transaction_hash):
    """Подписание транзакции"""
    sk = ecdsa.SigningKey.from_string(private_key, curve=ecdsa.SECP256k1)
    signature = sk.sign_digest(transaction_hash, sigencode=ecdsa.util.sigencode_der)
    return signature

# Пример
tx_hash = hashlib.sha256(b"transaction data").digest()
signature = sign_transaction(private_key, tx_hash)
print("Подпись:", signature.hex())
```

### Проверка подписи

```python
def verify_signature(public_key, signature, transaction_hash):
    """Проверка подписи"""
    vk = ecdsa.VerifyingKey.from_string(public_key[1:], curve=ecdsa.SECP256k1)
    try:
        vk.verify_digest(signature, transaction_hash, sigdecode=ecdsa.util.sigdecode_der)
        return True
    except:
        return False

# Проверка
is_valid = verify_signature(public_key, signature, tx_hash)
print("Подпись валидна:", is_valid)
```

## 📱 Практические рекомендации

### Для начинающих

1. **Начни с малых сумм** — потренируйся на небольших суммах
2. **Используй проверенные кошельки** — Trust Wallet, Exodus, Electrum
3. **Сохрани seed-фразу** — запиши на бумаге, храни в безопасном месте
4. **Проверь адрес** — всегда проверяй адрес перед отправкой

### Для продвинутых

1. **Аппаратный кошелек** — для больших сумм
2. **Multisig** — кошелек с несколькими подписями
3. **Холодное хранение** — основные средства офлайн
4. **Горячий кошелек** — только для повседневных трат

### Безопасность

**Защита seed-фразы**:
- Металлические пластины для записи
- Сейф или банковская ячейка
- Разделение на части (Shamir's Secret Sharing)

**Защита от фишинга**:
- Проверяй URL сайтов
- Не переходи по ссылкам из email
- Используй закладки браузера

**Защита устройства**:
- Антивирус
- Регулярные обновления
- Двухфакторная аутентификация

## ⚠️ Частые ошибки

1. **Потеря seed-фразы** → Потеря доступа навсегда
2. **Отправка на неверный адрес** → Деньги потеряны
3. **Хранение ключей онлайн** → Риск взлома
4. **Использование ненадежных кошельков** → Кража средств
5. **Игнорирование обновлений** → Уязвимости безопасности

# Транзакции в криптовалютах

## 💸 Что такое транзакция?

**Определение**: Передача криптовалюты от одного адреса к другому, записанная в блокчейне.

## 📋 Структура транзакции Bitcoin

```
Транзакция
├── Версия
├── Входы (Inputs)
│   ├── Ссылка на предыдущую транзакцию
│   ├── Индекс выхода
│   └── Подпись (ScriptSig)
├── Выходы (Outputs)
│   ├── Сумма
│   └── Адрес получателя (ScriptPubKey)
└── Locktime
```

## 🔄 Жизненный цикл транзакции

```
1. Создание → 2. Подписание → 3. Трансляция → 
4. Mempool → 5. Майнинг → 6. Подтверждение
```

### Детально:

1. **Создание**: Пользователь формирует транзакцию
2. **Подписание**: Подпись приватным ключом
3. **Трансляция**: Отправка в сеть
4. **Mempool**: Ожидание в очереди
5. **Майнинг**: Включение в блок
6. **Подтверждение**: Добавление новых блоков

## 💰 Комиссии

**Зачем нужны**:
- Стимул для майнеров
- Защита от спама
- Приоритизация транзакций

**Расчет**:
```
Комиссия = Размер транзакции (байты) × Ставка (satoshi/байт)
```

**Рекомендации**:
- Высокая комиссия = быстрое подтверждение
- Низкая комиссия = может зависнуть в mempool

## ✅ Подтверждения

**1 подтверждение** = транзакция в блоке  
**6 подтверждений** = считается окончательной

**Почему 6?**: Практически невозможно отменить после 6 блоков

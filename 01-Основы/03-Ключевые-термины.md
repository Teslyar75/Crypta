# Ключевые термины и концепции

## 🔤 Базовый словарь

### Блокчейн (Blockchain)
**Определение**: Распределенная база данных, состоящая из цепочки блоков, каждый из которых содержит информацию о транзакциях.

**Аналогия**: Представь книгу учета, где каждая страница (блок) связана с предыдущей, и у каждого есть копия этой книги.

### Майнинг (Mining)
**Определение**: Процесс создания новых блоков и подтверждения транзакций с помощью вычислительной мощности.

**Аналогия**: Как добыча золота, но вместо лопаты используются компьютеры, решающие математические задачи.

### Хеш (Hash)
**Определение**: Уникальный цифровой отпечаток данных, созданный криптографической функцией.

**Пример**: 
```
Входные данные: "Hello World"
SHA-256 хеш: a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e
```

### Приватный ключ (Private Key)
**Определение**: Секретный код, который дает доступ к твоим криптовалютам.

**Аналогия**: Пароль от банковского счета, который НИКОГДА нельзя никому показывать.

### Публичный ключ (Public Key)
**Определение**: Адрес, который можно публично использовать для получения криптовалюты.

**Аналогия**: Номер банковского счета, который можно давать другим для получения денег.

### Кошелек (Wallet)
**Определение**: Программа или устройство для хранения приватных и публичных ключей.

**Типы**:
- **Горячий кошелек** (Hot Wallet) — подключен к интернету
- **Холодный кошелек** (Cold Wallet) — офлайн хранение

### Узел (Node)
**Определение**: Компьютер, который поддерживает работу блокчейн-сети.

**Типы**:
- **Полный узел** (Full Node) — хранит всю историю блокчейна
- **Легкий узел** (Light Node) — хранит только часть данных

## 🔐 Криптографические концепции

### Криптография с открытым ключом (Public Key Cryptography)
Система, где есть два ключа:
- **Публичный** — для шифрования (все могут видеть)
- **Приватный** — для расшифровки (только у владельца)

### Цифровая подпись (Digital Signature)
Математическое доказательство того, что транзакция была создана владельцем приватного ключа.

**Процесс**:
1. Создаешь транзакцию
2. Подписываешь её приватным ключом
3. Другие проверяют подпись публичным ключом

### Хеш-функция (Hash Function)
Функция, которая превращает любые данные в строку фиксированной длины.

**Свойства**:
- Детерминированность (одинаковый вход → одинаковый выход)
- Необратимость (нельзя восстановить исходные данные)
- Лавинный эффект (малое изменение → полностью другой хеш)

## ⛓️ Блокчейн концепции

### Блок (Block)
Контейнер с данными о транзакциях.

**Структура блока**:
```
┌─────────────────────────┐
│   Заголовок блока       │
├─────────────────────────┤
│ - Хеш предыдущего блока │
│ - Временная метка       │
│ - Nonce                 │
│ - Merkle Root           │
├─────────────────────────┤
│   Транзакции            │
│ - Транзакция 1          │
│ - Транзакция 2          │
│ - ...                   │
└─────────────────────────┘
```

### Консенсус (Consensus)
Механизм, с помощью которого сеть соглашается с состоянием блокчейна.

**Основные типы**:
- **Proof of Work (PoW)** — доказательство работы
- **Proof of Stake (PoS)** — доказательство доли
- **Delegated Proof of Stake (DPoS)** — делегированное доказательство доли

### Форк (Fork)
Разделение блокчейна на две версии.

**Типы**:
- **Soft Fork** — обратно совместимое обновление
- **Hard Fork** — несовместимое обновление (создает новую криптовалюту)

## 💸 Транзакционные термины

### UTXO (Unspent Transaction Output)
Модель учета, где отслеживаются неизрасходованные выходы транзакций.

**Аналогия**: Как наличные купюры — ты не можешь потратить "часть" купюры, только целую.

### Mempool (Memory Pool)
Очередь неподтвержденных транзакций, ожидающих включения в блок.

### Комиссия (Transaction Fee)
Плата майнерам за включение транзакции в блок.

**Принцип**: Чем выше комиссия, тем быстрее обработается транзакция.

### Подтверждение (Confirmation)
Количество блоков, добавленных после блока с твоей транзакцией.

**Пример**: 6 подтверждений = твоя транзакция + 5 блоков после неё

## 🎯 Продвинутые концепции

### Смарт-контракт (Smart Contract)
Программа, которая автоматически выполняется при выполнении условий.

**Пример**: "Если Алиса отправит 1 ETH, то автоматически получит токены"

### Токен (Token)
Цифровой актив, созданный на существующем блокчейне.

**Типы**:
- **Utility Token** — дает доступ к сервису
- **Security Token** — представляет долю в активе
- **NFT** — уникальный невзаимозаменяемый токен

### DeFi (Decentralized Finance)
Финансовые услуги без посредников на базе смарт-контрактов.

**Примеры**: кредитование, обмен, страхование

### Gas (Газ)
Единица измерения вычислительной работы в Ethereum.

**Аналогия**: Как бензин для машины — нужен для выполнения операций.

### Оракул (Oracle)
Сервис, который предоставляет внешние данные для смарт-контрактов.

**Пример**: Курс валют, погода, результаты спортивных матчей

## 📊 Экономические термины

### Капитализация (Market Cap)
Общая стоимость всех монет в обращении.

**Формула**: Цена монеты × Количество монет

### Волатильность (Volatility)
Степень изменения цены актива.

**Высокая волатильность** = большие колебания цены

### Ликвидность (Liquidity)
Легкость покупки/продажи актива без влияния на цену.

### Халвинг (Halving)
Уменьшение награды майнерам вдвое (происходит в Bitcoin каждые 4 года).

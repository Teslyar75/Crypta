ХМАРНІ ОБЧИСЛЕННЯ (Cloud Computing) — Відповіді на питання
================================================================

1. Що таке cloud computing?
   Cloud computing (хмарні обчислення) — це модель надання обчислювальних
    ресурсів (сервери, сховища, бази даних, мережеві можливості, програмне 
    забезпечення) через Інтернет за запитом. Замість власних серверів і 
    дата-центрів користувач отримує доступ до ресурсів провайдера та 
    оплачує лише те, що використовує.

2. Яка головна перевага хмарних технологій?
   Головна перевага — масштабованість та економія. Не потрібно купувати власне 
   обладнання, можна швидко збільшувати або зменшувати ресурси за потреби, 
   оплачувати лише фактичне використання (pay-as-you-go).

3. Які моделі хмарних сервісів існують?
   - IaaS (Infrastructure as a Service) — інфраструктура як послуга
   - PaaS (Platform as a Service) — платформа як послуга
   - SaaS (Software as a Service) — програмне забезпечення як послуга

4. Наведіть приклад SaaS.
   Приклади: Google Workspace (Gmail, Docs), Microsoft 365, Salesforce, Dropbox, 
   Slack, Zoom, Netflix.

5. Що таке IaaS?
   IaaS (Infrastructure as a Service) — модель, де провайдер надає віртуальні 
   машини, мережу, сховище. Користувач сам керує ОС, додатками та даними. 
   Приклади: Amazon EC2, Microsoft Azure VM, Google Compute Engine.

6. Який тип хмари використовується лише всередині однієї компанії?
   Приватна хмара (Private Cloud) — інфраструктура, що експлуатується виключно 
   однією організацією.

7. Хто відповідає за оновлення операційної системи на віртуальній машині в IaaS?
   У моделі IaaS за оновлення ОС відповідає сам клієнт (користувач). Провайдер 
   надає лише віртуальну машину та базову інфраструктуру.

8. Для чого найчастіше використовують хмарні технології?
   Для зберігання даних, хостингу веб-сайтів і застосунків, резервного копіювання, 
   розробки та тестування, аналітики даних, машинного навчання, потокового відео 
   та інших обчислювальних задач.

9. Що відбувається з хмарним застосунком при різкому зростанні навантаження?
   Хмарні платформи підтримують автоматичне масштабування (auto-scaling): 
   при зростанні навантаження додаються додаткові ресурси (сервери, інстанси), 
   при зниженні — вони звільняються. Застосунок залишається доступним і продуктивним.

10. Назвіть будь-якого хмарного провайдера.
    Приклади: Amazon Web Services (AWS), Microsoft Azure, 
    Google Cloud Platform (GCP), Oracle Cloud, IBM Cloud, DigitalOcean.
